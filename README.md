KAI ANGEL

Добро пожаловать на наш сайт, посвященный невероятному артисту Kai Angel! Этот проект создан, чтобы предоставить фанатам возможность узнать больше о его творчестве, событиях и обновлениях.

## Актуальность
Сайт обладает следующими возможностями:

Информация о Kai Angel: Узнайте о биографии, творческом пути и последних новостях артиста.

Календарь событий: Следите за предстоящими мероприятиями и концертами. В нашем разделе событий вы найдете всю необходимую информацию о датах и месте проведения.

Регистрация пользователей: Зарегистрируйтесь, чтобы получать актуальные обновления и новости о Kai Angel.

Админ-панель: Удобный интерфейс для администраторов, который позволяет:

Добавлять новые события и ивенты
Управлять зарегистрированными пользователями
Настраивать даты и места проведения мероприятий

## Запуск
### Вариант 1: локально
1. Установить зависимости: pip install django-jazzmin, pip install django, pip install, pip install Pillow
2. Применить миграции: python manage.py makemigrations
python manage.py migrate
3. Запустить сервер: python manage.py runserver
4. Доступ: http://127.0.0.1:8000/
